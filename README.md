# maryamqadeer-insights-WellPluse_BY_Maryam_Qadeer_ACT_AI_FINAL_PROJECT
WellPulse is an AI-powered health platform by Maryam Qadeer (BZU ACT_AI Batch 2) offering personalized metabolic evaluations, custom macro calculators, and a PCOS module. Built with Next.js and Tailwind CSS, it features dynamic BMI assessments, guided workouts, and an AI wellness coach.
